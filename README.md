# 🎓 MACC Students Data Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing MACC student data using **Power BI**. The dashboard provides insights into student enrollment, course performance, payments, outstanding dues, dropouts, and student trends over time.

The project consists of two interactive dashboard pages:

* **Dashboard Overview** – High-level analysis of students, enrollment, payments, courses, and dropouts.
* **Course & Financial Analysis** – Detailed analysis of course-wise student performance, dropouts, received amounts, and due amounts.

## 📊 Key Metrics

The dashboard includes key performance indicators such as:

* Total Received Amount
* Total Enrollment Amount
* Total Due Amount
* Total Students
* Average Amount per Student
* Total Number of Courses
* Average Amount per Course
* Total Number of Dropouts

## 📈 Dashboard Page 1 – Student Overview

The main dashboard provides insights into:

* Total received amount
* Total enrollment amount
* Total due amount
* Total number of students
* Average amount per student
* Total number of courses
* Average amount per course
* Total number of dropouts
* Students by course enrolled
* Due amount trends
* Gender-based student analysis
* Year-wise student and financial analysis

A year slicer is included to allow interactive filtering and comparison across different years.

## 📊 Dashboard Page 2 – Course & Financial Analysis

The second page focuses on detailed course and financial performance analysis, including:

* Total number of dropouts by course enrolled
* Course-wise student analysis
* Total received amount by year
* Total due amount by year
* Student joining trends
* Enrollment and payment analysis
* Course-wise financial performance

## 💡 Key Business Insights

* The dashboard provides a complete overview of student enrollment and financial performance.
* Course-wise analysis helps identify courses with higher student enrollment.
* Dropout analysis helps identify courses that may require additional attention.
* Comparing received amounts with due amounts helps monitor outstanding payments.
* Year-wise analysis makes it easier to understand changes in student enrollment and financial performance over time.
